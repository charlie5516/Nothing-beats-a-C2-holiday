车手简介
<p>夏尔·勒克莱尔是法拉利车队的F1车手，自2019年加入车队以来，以其卓越的单圈速度和强势的比赛表现成为车队争冠的希望。</p>
<p>2025赛季，勒克莱尔展现了出色的适应能力。他对赛车强大的操控能力和优秀的驾驶天赋在本赛季得到了充分展示。在匈牙利，勒克莱尔取得了法拉利本赛季唯一一个杆位。</p>

<p>卡洛斯·塞恩斯在2025赛季转会至威廉姆斯车队，成为车队的F1车手。他在先前的职业生涯中积累了丰富的经验，为威廉姆斯带来了宝贵的技术反馈。</p>
<p>塞恩斯以出色的策略能力和稳定的比赛节奏著称。2025赛季，他帮助威廉姆斯车队在中游集团的争夺中获得突破。在巴库和卡塔尔，塞恩斯为车队斩获两个领奖台。</p>
